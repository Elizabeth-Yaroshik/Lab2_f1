### Названия справочников

1. **Справочник «Пилоты формулы-1»**  
2. **Справочник «Результаты гонок»**  

### Перечень колонок

#### Справочник «Пилоты формулы-1»

| Колонка                   | Тип данных                | Описание                         |
|---------------------------|---------------------------|----------------------------------|
| ID                        | целое (PK)                | уникальный идентификатор         |
| ФИО                       | текст, обязательное поле  | полное имя пилота                |
| Дата рождения             | дата, обязательное поле   | в формате ГГГГ-ММ-ДД             |
| Номер болида              | целое число               | от 1 до 99                       |
| Многострочный комментарий | текст (многострочный)     | достижения, заметки              |

#### Справочник «Результаты гонок»

| Колонка               | Тип данных                | Описание                         |
|-----------------------|---------------------------|----------------------------------|
| ID                    | целое (PK)                | уникальный идентификатор         |
| Пилот                 | целое (FK)                | ссылается на `ID` из «Пилоты»    |
| Гонка                 | текст, обязательное поле  | название этапа (Гран-при)        |
| Дата гонки            | дата, обязательное поле   | дата проведения                  |
| Финишная позиция      | целое число               | место, занятое в гонке           |
| Время (сек)           | числовое с фикс. запятой  | время в секундах (до 3 знаков после запятой) |
